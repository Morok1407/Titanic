# Titanic: прогноз выживания

Небольшая полносвязная нейросеть на NumPy, обученная на историческом датасете из 1 309 пассажиров.
Обучение и прогноз работают на CPU. Игровой веб-интерфейс работает локально на этом компьютере.

## Открыть приложение

Дважды нажмите **Start.cmd** в корне проекта. Откроется страница `http://127.0.0.1:8000`.
Окно сервера нужно оставить открытым; для остановки нажмите в нём Ctrl+C.
Если порт 8000 занят, используйте команду ниже с `--port 8001`.

```powershell
.\.venv\Scripts\python.exe -m titanic.server --open-browser
```

Создайте пассажира, выберите пол, возраст и класс билета, укажите родственников.
В «Деталях путешествия» доступны палуба, цена билета и порт посадки.
Кнопка с кубиком предлагает вымышленных пассажиров для экспериментов.
«Узнать свою историю» отправляет параметры сохранённой нейросети и показывает её оценку.
Изменение признаков помечает предыдущий результат как устаревший и предлагает пересчитать его.
Имя отображается только на билете и не передаётся модели.

Интерфейс адаптирован для узкого экрана, поддерживает клавиатуру и уменьшение анимации
через системную настройку reduced motion. Изображение, стили и скрипты хранятся в проекте;
после установки зависимостей интернет для прогнозов не нужен. Приложение не сохраняет анкеты.

## Установка и запуск (PowerShell)

Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m titanic.train
.\.venv\Scripts\python.exe -m titanic.predict --input examples/passenger.json
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Команды выполняются из корня проекта. При уже настроенном окружении начинать можно с обучения или прогноза.
Обучение перезаписывает модель и отчёты. Полученные метрики и фактическое время запуска —
в [отчёте обучения](reports/training_report.md).

## Что сохранено

- `models/titanic_mlp.npz`: веса выбранной нейросети, медианы, масштабирование и порог; формат NumPy + JSON без pickle.
- `reports/metrics.json`: метрики и параметры всех кандидатов, версии библиотек, хеш датасета.
- `reports/split_indices.json`: индексы строк обучающей, валидационной и тестовой выборок.
- `reports/training_history.json`: ошибка обучения и валидации по эпохам.
- `reports/test_predictions.csv`: прогнозы на отложенном тесте.
- `examples/passenger.json`: пример данных для прогноза.

## Входные данные

| Поле | Формат | Если не указано |
| --- | --- | --- |
| `sex` | `female` / `male` | Обязательное поле |
| `pclass` | 1, 2 или 3 | Обязательное поле |
| `age` | Возраст в годах, 0–100; допустимы дробные значения | Медиана train и индикатор пропуска |
| `sibsp` | Число братьев, сестёр и супругов на борту, целое 0–20 | 0 |
| `parch` | Число родителей и детей на борту, целое 0–20 | 0 |
| `fare` | Стоимость билета в исторических фунтах, 0–1000 | Медиана log(1 + fare) на train |
| `deck` | Палуба `A`–`G`, `T` или `UNKNOWN` | `UNKNOWN` |
| `embarked` | Порт посадки `C`, `Q`, `S` или `UNKNOWN` | `UNKNOWN` |

`age`, `fare`, `deck`, `embarked` допускают `null`.
Индикаторы пропусков создаются для числовых полей, в которых были пропуски на train.
В текущем разбиении это возраст; единственный пропуск стоимости оказался вне train.
Ограничения чисел — проверка ввода, а не гарантия наличия похожих примеров в обучении.
Например, возраст свыше максимума обучающих данных приводит к экстраполяции.
Палуба получена из каюты; точное местонахождение при крушении неизвестно.
Класс билета служит показателем условий проезда; отдельного статуса члена экипажа нет.
Источник, поля и пропуски описаны в [data/README.md](data/README.md).

## Прогноз из Python

```python
from titanic.predict import SurvivalPredictor

predictor = SurvivalPredictor()  # Загрузить один раз при старте сервера.
result = predictor.predict({
    "sex": "female", "pclass": 2, "age": 28,
    "sibsp": 0, "parch": 0, "deck": "UNKNOWN", "embarked": "S",
})
print(result["survival_probability"])  # Значение от 0 до 1.
print(result["predicted_survived"])    # 0 или 1, порог 0.5.
```

`ValueError` означает некорректный ввод. `missing_inputs` перечисляет неизвестные поля,
`defaulted_inputs` — счётчики родственников, для которых подставлен 0.
В UI вероятность следует назвать «оценкой модели»: индивидуальный исход по нескольким признакам достоверно установить нельзя.
Вероятности отдельно не калибровались.

## Метод проверки

Пять частей с группировкой по номеру билета: три для обучения, одна для выбора сети и эпохи,
одна для итоговой проверки. Медианы и масштабирование обучаются только на train.
Шлюпка и номер тела исключены как признаки, раскрывающие ответ.
Три заранее заданных варианта сети сравниваются по validation log loss.
Тест не участвует в подборе. Рядом с нейросетью оцениваются постоянный прогноз и логистическая регрессия.
Модель в файле — именно та, для которой приведены тестовые метрики, без дообучения на тесте.

Обратное распространение ошибки и Adam реализованы в `titanic/network.py`.
Градиенты проверяются численным дифференцированием; дополнительно проверяется обучение на простой задаче.
Логистическая регрессия для сравнения — сеть без скрытых слоёв, с фиксированными 600 эпохами и L2 alpha = 1.
В текущем окружении `.venv` использует уже установленные NumPy и pandas через system-site-packages.
На другом компьютере команды выше устанавливают эти две библиотеки в самостоятельное окружение.

## Веб-интерфейс и API

- `web/`: интерфейс на HTML, CSS и JavaScript без сборки и сторонних CDN.
- `titanic/server.py`: локальный сервер на стандартной библиотеке Python; слушает только `127.0.0.1`.
- `GET /api/model`: состояние модели и фактические метрики из отчёта.
- `POST /api/predict`: JSON с полями из таблицы выше; возвращает тот же результат, что `SurvivalPredictor.predict`.
- `tests/test_server.py`: проверки API, ошибок ввода, статических ресурсов и соответствия прогноза модели.

Незавершённая ранее загрузка scikit-learn не требуется: финальная сеть реализована на NumPy.
Датасет и обученные веса полные и проверены. При переносе проекта достаточно `requirements.txt`.

Иллюстрация `web/assets/titanic-night.png` создана встроенным ImageGen.
Описание генерации сохранено в `web/assets/README.md`.
