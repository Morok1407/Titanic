# Датасет Titanic

Скачан 2 октября 2026 года непосредственно с Kaggle:
[The Complete Titanic Dataset — vinicius150987/titanic3](https://www.kaggle.com/datasets/vinicius150987/titanic3).

Адрес скачивания: https://www.kaggle.com/api/v1/datasets/download/vinicius150987/titanic3

## Файлы

- `titanic.csv` — таблица в UTF-8 для будущего обучения, 1 309 строк и 14 столбцов.
- `raw/titanic3.zip` — оригинальный архив Kaggle.
- `raw/titanic3/titanic3.xls` — исходная таблица из архива.
- `quality_report.json` — результаты проверки и SHA-256 файлов.

CSV получен из первого листа XLS без заполнения пропусков, удаления признаков или генерации пассажиров. Целые числовые значения записаны без дробной части. Пустые ячейки сохранены пустыми. Это небольшой исторический набор, а не большой синтетический датасет. Для учебного проекта можно начать с него, однако размер ограничивает возможности нейросети и надёжность оценки качества.

## Поля

| Поле | Значение | Пропусков |
| --- | --- | ---: |
| `survived` | Целевая переменная: 1 — выжил, 0 — погиб | 0 |
| `pclass` | Класс билета: 1, 2 или 3; приблизительный показатель социального положения | 0 |
| `name` | Имя пассажира | 0 |
| `sex` | Пол | 0 |
| `age` | Возраст в годах, у младенцев может быть дробным | 263 |
| `sibsp` | Число братьев, сестёр и супругов на борту | 0 |
| `parch` | Число родителей и детей на борту | 0 |
| `ticket` | Номер билета | 0 |
| `fare` | Стоимость билета | 1 |
| `cabin` | Каюта, иногда несколько номеров | 1 014 |
| `embarked` | Порт посадки: C — Шербур, Q — Квинстаун, S — Саутгемптон | 2 |
| `boat` | Спасательная шлюпка; исключить из входов модели | 823 |
| `body` | Номер найденного тела; исключить из входов модели | 1 188 |
| `home.dest` | Место проживания / назначения | 564 |

В файле 500 выживших и 809 погибших. Полных дубликатов строк нет. Историческая достоверность каждой записи отдельно не проверялась.

## Использование при обучении

`survived` служит ответом для обучения, но не входным признаком. `boat` и `body` известны после катастрофы и создают утечку целевой переменной. Их нельзя использовать для прогноза по данным пассажира до катастрофы.

Начальные входы: `sex`, `pclass`, `age`, `sibsp`, `parch`, `fare`, `embarked`. Из `cabin` можно выделить палубу, сохраняя категорию «неизвестно». Точное местонахождение человека в момент катастрофы в таблице отсутствует. Отдельного признака должности или статуса члена экипажа нет.

Обработка пропусков и кодирование категорий реализованы в `titanic/features.py`. Данные разделены на обучающую, валидационную и тестовую выборки, преобразования обучаются только на обучающей части. Результаты находятся в [отчёте обучения](../reports/training_report.md).

## Повторное скачивание и проверка

Из корня проекта в PowerShell:

```powershell
Invoke-WebRequest -Uri 'https://www.kaggle.com/api/v1/datasets/download/vinicius150987/titanic3' -OutFile 'data/raw/titanic3.zip'
Expand-Archive -LiteralPath 'data/raw/titanic3.zip' -DestinationPath 'data/raw/titanic3' -Force
python -m pip install xlrd==2.0.2
python scripts/prepare_dataset.py
```

Повторное скачивание может вернуть обновлённую версию Kaggle. Дата в скрипте относится к первоначальному скачиванию; при обновлении измените её. Сведения о лицензии и актуальные условия использования нужно смотреть на странице источника, лицензия на данные здесь не переопределяется.
